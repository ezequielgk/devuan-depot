Personal APT repository for Debian 13 (trixie) / Devuan 6. Packages are built via GitHub Actions, without compiling anything locally.

ezequiel@devuan: ~ 
# 1. import repo public key
curl -fsSL https://ezequielgk.github.io/devuan-depot/public.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/devuan-depot.gpg
sudo chmod a+r /usr/share/keyrings/devuan-depot.gpg
ezequiel@devuan: ~ 
# 2. add the repo
echo "deb [signed-by=/usr/share/keyrings/devuan-depot.gpg] https://ezequielgk.github.io/devuan-depot trixie main" \
  | sudo tee /etc/apt/sources.list.d/devuan-depot.list
sudo chmod a+r /etc/apt/sources.list.d/devuan-depot.list
ezequiel@devuan: ~ 
# 3. install
sudo apt update
sudo apt install <package>

how it works

Each package has its own workflow in .github/workflows. GitHub Actions builds the source code inside a debian:trixie container, assembles the .deb, and publishes it signed on the gh-pages branch — this very page.
