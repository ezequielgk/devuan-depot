Paquetes .deb compilados para Debian 13 (trixie) / Devuan 6, sin tener que compilar nada localmente.

ezequiel@devuan: ~ 
# 1. importar la clave publica del repo
curl -fsSL https://ezequielgk.github.io/devuan-depot/public.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/devuan-depot.gpg

# 2. agregar el repo
echo "deb [signed-by=/usr/share/keyrings/devuan-depot.gpg] https://ezequielgk.github.io/devuan-depot trixie main" \
  | sudo tee /etc/apt/sources.list.d/devuan-depot.list

# 3. instalar
sudo apt update
sudo apt install swayfx

paquetes

cómo funciona

Cada paquete tiene su propio workflow en .github/workflows. GitHub Actions compila el código fuente dentro de un contenedor debian:trixie, arma el .deb, y lo publica firmado en la rama gh-pages — esta misma página.

suite: trixie · arch: amd64 firmado con GPG
